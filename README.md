# Education Leadership Analytics Dashboard

An interactive analytics dashboard designed for educational administrators and leadership teams. This tool provides real-time insights into institutional performance through intuitive visualizations and comprehensive data displays.

## Overview

The Education Leadership Analytics Dashboard consolidates key educational metrics into a single, easy-to-navigate interface. Built for district superintendents, college deans, department chairs, and other education leaders, it transforms raw institutional data into actionable insights.

## Features

- **Enrollment Trends** - Track student enrollment across departments with interactive bar charts showing year-over-year comparisons
- **Student Performance** - Monitor graduation rates over multi-year periods with trend analysis and projections
- **Resource Allocation** - Visualize budget distribution across institutional priorities with doughnut charts
- **Faculty Metrics** - Overview of faculty count, student-to-faculty ratios, and departmental staffing levels
- **Department Rankings** - Tabular view of top-performing departments by key performance indicators
- **Real-Time Statistics** - At-a-glance stat cards for total students, graduation rate, faculty count, and average GPA

## Technology Stack

- **HTML5** - Semantic markup and accessible structure
- **CSS3** - Modern styling with CSS Grid and Flexbox for responsive layouts
- **JavaScript (ES6+)** - Dynamic interactivity and data manipulation
- **Chart.js** - Professional-grade interactive charts and visualizations

## Getting Started

1. Clone this repository
2. Open `index.html` in any modern web browser
3. No build process or server required - it works directly from the file system

## Dashboard Sections

### Summary Statistics
Four key metric cards displaying Total Students (12,450), Graduation Rate (87.3%), Faculty Count (892), and Average GPA (3.24).

### Enrollment by Department
A bar chart breaking down student enrollment across major academic departments including Engineering, Business, Sciences, Arts & Humanities, Health Sciences, and Education.

### Graduation Rate Trends
A line chart showing graduation rate progression over a five-year period (2021-2025), allowing leaders to identify improvement trends or areas of concern.

### Budget Allocation
A doughnut chart illustrating how institutional funds are distributed across categories such as Instruction, Research, Student Services, Administration, Facilities, and Technology.

### Top Performing Departments
A data table ranking departments by composite scores derived from graduation rate, student satisfaction, and research output.
